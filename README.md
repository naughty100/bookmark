# 书签创作工具 | Bookmark Creator

[中文](#书签创作工具) | [English](#bookmark-creator)

## 书签创作工具

这是一个基于[Next.js](https://nextjs.org)开发的书签设计与创作工具，让用户可以自由创建、定制和导出精美的书签。

### 功能特点

- 🎨 自定义背景：支持纯色、线性渐变和径向渐变背景
- 📝 文本编辑：添加、编辑和样式化文本元素
- 🖼️ 图片导入：上传并裁剪图片作为书签元素
- 📐 拖拽调整：直观地拖拽和调整元素位置与大小
- 💾 导出功能：将设计导出为高质量PNG图片
- 🌐 多语言支持：支持中英文界面切换

### 开始使用

首先，运行开发服务器：

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看项目。

你可以通过修改 `app/bookmark/page.tsx` 开始编辑主页面。

### 技术栈

本项目使用以下技术：

- Next.js 15.3.1 - React框架
- TypeScript - 类型安全
- Tailwind CSS - 样式设计
- Canvas API - 图像处理与导出

## Bookmark Creator

This is a bookmark design and creation tool developed with [Next.js](https://nextjs.org), allowing users to freely create, customize, and export beautiful bookmarks.

### Features

- 🎨 Custom Backgrounds: Support for solid colors, linear gradients, and radial gradients
- 📝 Text Editing: Add, edit, and style text elements
- 🖼️ Image Import: Upload and crop images as bookmark elements
- 📐 Drag and Adjust: Intuitively drag and adjust element positions and sizes
- 💾 Export Functionality: Export designs as high-quality PNG images
- 🌐 Multi-language Support: Interface available in both Chinese and English

### Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the project.

You can start editing the main page by modifying `app/bookmark/page.tsx`.

### Tech Stack

This project uses the following technologies:

- Next.js 15.3.1 - React framework
- TypeScript - Type safety
- Tailwind CSS - Style design
- Canvas API - Image processing and export
